# SchemaFlux

SchemaFlux v2 is a Go library for typed language-model operations. Its module,
packages, tests, examples, and versioned documentation live in [`v2/`](v2/).
The repository root contains project and release files; it has no Go source.

Install the library with:

```bash
go get github.com/monstercameron/schemaflux/v2@v2.0.1
```

Import `github.com/monstercameron/schemaflux/v2` in your Go code. Moving the
module into `v2/` does not add another path segment to imports. See the
[v2 README](v2/README.md) for a first call, provider setup, packages, and
migration notes.
